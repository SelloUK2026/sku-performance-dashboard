Tesco user guide

Second-stage selection

  1. Export the Tesco promotion worktable, enter Yes in column T for candidates, then import it here.
  2. Upload the latest Tesco Catalogue for the event. The latest Offer SKU file is already captured when Tesco data is first imported in the calculation tool.
  3. Enter the event dates, Tesco-defined categories and limits. Assign an event category and fixed Level 1 group to each selected SKU.
  4. A Tesco SKU used in an overlapping saved event is blocked. Another Tesco SKU for the same Wooper product remains available.
  5. Generate the form only when the quota and required fields pass. The saved snapshot becomes the overlap record for future events.
  6. If a nomination was submitted outside this tool, import the completed nomination form under Saved Tesco events and confirm any unmatched Tesco SKU.
